## この試作で変えたこと

「スマホで読めるように情報を減らす」というv14の判断を撤回し、**情報は適切に示しながら、同時表示するテーマを1つに絞る**。
常設サイドバー・多項目一覧・常設高低グラフを復活させるのではなく、映像内に短い説明カードを置く。

各ステージで、**位置を光のライン／ラベルで示す → そこに関係する数字や理由を表示 → 次の情報に切り替える**。

| 順 | 画面内のテーマA | 続くテーマB |
|---|---|---|
| コース | スタート→最初のコーナーの距離 | 最後の直線の長さ |
| 起伏 | 上り坂がある区間 | 坂の高さ・その後の区間 |
| 隊列形成 | ゲートから位置移動 | 隊列が落ち着く |
| 最終確認 | 全頭の位置関係 | 注目馬だけ番号を大きく表示 |

表示テキストは `explainer_facts.json` から供給。東京と中山で異なる情報が出る。
各テーマは同時に**見出し＋主情報＋短い補足＋該当位置のラベル**のみ。別テーマを並べて一緒に読むUIにはしない。

# けいばびより｜Scene03 v16：全景ピックアップ表示

**目的：**「直線だけを切り抜くとコース内の位置が分からない」というv15の視認性問題を改善する。スマホ視聴者が、いま説明中の直線・坂がコースのどこかを理解できるようにする。

## 変更点（v15 → v16）

- **コース説明・起伏説明で、常にコース全景を維持する。** 直線だけを接写して全景が消えるv15のスロープカメラを廃止。
- 全景と同じカメラ位置・拡大率を維持しながら、説明対象区間だけ幅広いオレンジ／クリーム色の帯で強調する。「コースのどの部分か」がすぐ確認できる。
- 東京D1400：「スタート→3角」、「最後の直線」、「上り坂」、「坂のあとの区間」を順次ピックアップする。
- 中山芝2000A：「スタート→1角」、「最後の直線」、「ゴール前の上り区間（位置）」、「同じ坂の高低差」を順次ピックアップする。
- 説明カードは一度に1項目。画面左下に置き、コースの画面内全景を遮らないようにカメラを少し上方へ配置する。
- 既存の「隊列形成 → 静止後の注目馬番号強調」のシーケンスはそのまま維持する。
- すべての選択範囲はレース／コースデータから描画し、コース専用の手書き画像として書き込まない。

## 保存と保護

- 新規ブランチ `work/scene03-course-context-v16`、ディレクトリ `vnext-v16/`。
- 前版v10～v15、本番main、既存GitHub Pages、正本SQLite DBは**変更しない**。
- **正式予想データ未接続、開発用デモ。** 16頭東京D1400、12頭中山芝2000Aのデモデータを利用。8・18頭の入力検証も維持。
- CS: コース種別・説明の正本として参考。平面曲線／高低座標は旧v10のJRA資料を人手でトレースした**概略**であり、公式測量データではない。
- 色帯は説明用のCGであって実際の着色走路ではない。上りの精密開始位置・勾配を公式の3D実測と主張しない。坂の位置情報は引き続き追加検証を要する。
- 全レースのコース幾何データが揃ったわけではない。登録済みは上記2コースのみ。未登録コースはエラーで停止（fail-fast）。

## 改善内容

v16の「コース全景のうち説明する区間をピックアップ」方式を保持しながら、走路上の基準点を明示した。

- **START／スタート**：緑の旗アイコン、緑背景、読みやすい大きな文字。
- **GOAL／ゴール**：チェッカー柄の旗、茶金背景、読みやすい大きな文字。
- スタートとゴールは `course_geometry.json` の `trace.start` ／ `trace.goal` を各コースの3D描画曲線の最近傍に写像したもので、静的な画面座標ではない。コース、レースが変わっても自動で再投影される。
- 「コース紹介」「起伏説明」の間は **2つとも固定表示**。指示対象の色帯だけが順次切り替わる。
- 隊列の馬番が現れると両ラベルは隠し、画面の混雑を防止する。
- STARTの説明時に「スタート」吹き出しを重複させない。
- 「坂のあと」の吹き出しがGOALに重なった不具合を検出。START/GOALを優先し、説明の吹き出しを上方へ移す。ずらした場合も線で元位置を指す。
- 英語文字をやや拡大し、スマホ縮小表示での区別を強化した。

## 正確性・未完成点

コース点群、スタート・ゴール・起伏地点は以前のJRA公開コース図を人手でトレースした概略入力。START/GOALのラベルはその *トレース上の基準点* を指す。**実測座標・測量3Dであると主張しない。** 新KBVの`jv_r_CS`は文章やコース区分のデータであり、各地点の正確な3D座標は含まない。

現時点で詳細な図形を登録しているのは東京D1400・中山芝2000Aの2条件のみ。未登録コースはfail-fastで拒否。全JRAコースへの対応、公式図での再認証、正確な標高座標、実PS3/Phase1、音声WAVとの同期などは今後の課題。

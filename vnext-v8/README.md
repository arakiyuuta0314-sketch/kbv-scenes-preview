## 仕様上の注意

- JRA-VANは東京ダート1400mについて「スタートから3コーナーまで約440m」「3～4コーナーはほぼ平坦」と説明している。映像の『隊列完成』は最初のコーナーの手前・進入時・途中など、予想の大まかな展開に沿う区切りとして設計する。数十メートル・秒単位の位置精度は要求せず、予想以上の地理的正確さを演出しない。現行のv8が表せるのは手前までで、コーナー途中を描くにはモデルの拡張が必要。
- コースの輪郭・勾配はJRA図の概略トレース。測量済み実測3D・距離ごとの正確な勾配ではない。
- 進路・隊列・馬番の動きは予測・表示サンプル。公式実走GPS・確定位置ではない。馬の幅方向位置を枠番から補完する処理はしない。
- KBV PICKへの連携は `course_facts_v7.js` が出す根拠付き事実だけを候補にする。実際の予想ロジックは未変更。
- 3種類の表現：コース概要 → 発走後の動き → 静止して説明。シーンの秒数は固定せずWAV総尺に連動。語句単位の厳密な時刻同期やMP4レンダリングは未完成。
- v8で使うコースマスタは **v5の固定スナップショット**。将来の正本更新時は、SHAとスキーマを再確認した上で再エクスポート・QAする。古いv7を最新DB対応と見なさない。

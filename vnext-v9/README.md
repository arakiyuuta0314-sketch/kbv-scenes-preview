# Scene03 v9 | コーナー左右回りの修正

目的：JRA公式図と隊列アニメーションの曲がり方向を一致させる。

## 原因

v8以前の拡大走路は、スタート・最初のコーナーの弦（直線）からのずれをY座標へ足す変換だった。その計算では、コーナーが実際とは逆方向に見えることがあった。

また中山の周回原点をまたぐ際、前方1点だけを使うレールの接線計算が反転し、内外ラチが一瞬約200px飛んで交差していた。

## 修正

- jra_geometry_v9.js：JRA図から手動トレースした中心線を、発走時の接線方向基準で回転投影。曲がる向きそのものを保持する。
- 東京ダ1400：画面右から左へ進み、3コーナーに向けて下側へ曲がる（左回り）。
- 中山芝2000 A：画面左から右へ進み、コーナーに向けて下側へ曲がる（右回り）。
- レール幅方向の法線を中央差分に変更し、ループ原点での反転とラチの飛びを解消。
- 既存の起伏・コース位置・隊列形成・静止解説・ナレーションWAV尺への追従は維持。
- 予想データは変更しない。JRA図からの手動トレースは実測GIS・測量3D・実走GPSではない。

出典：
東京 https://www.jra.go.jp/facilities/race/tokyo/course/index.html
中山 https://www.jra.go.jp/facilities/race/nakayama/course/index.html

## QA結果

- ブラウザ描画の幾何外積によるカーブ方向：東京は負（左回り）、中山は正（右回り）。
- 連続するラチ座標間の最大距離：東京18.10px、中山20.75px。修正前の中山では約206pxの飛びがあった。
- 出走頭数：東京16、中山12。両条件で馬番・停止後解説表示、JavaScriptエラー0件。
